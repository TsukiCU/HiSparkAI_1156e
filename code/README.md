# AI/modelProcessing

HiSpark Studio AI是面向开发者，聚焦嵌入式场景的超轻量级AI应用开发平台，具备模型压缩、模型转换、应用开发、端侧部署、性能调优等功能。

- 模型量化  将高精度模型压缩为低精度模型，降低模型体积与计算复杂度，适配端侧算力与内存资源受限的运行环境。
- 模型转换  将主流训练框架下训练完成的模型转换为端侧平台可执行的格式，实现模型在嵌入式设备上的运行。
- 模型部署  支持一键下载量化转换产物。
- 模型性能验证  在端侧设备上对模型推理性能进行测试，评估推理时间、内存占用等关键指标，辅助性能优化。
- 模型精度验证  对比量化、转换前后的模型推理结果，验证端侧部署模型精度变化。
