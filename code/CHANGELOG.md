# 更改日志

`HiSpark Studio AI for VS Code`插件的所有更改将会记录在此文件中。

## [26.1.1] - 2026-01-31

新增

- 模型选择功能，支持连接远程服务器、选择待处理模型
- 模型量化功能，支持用户配置参数、上传数据集，支持模型量化，支持结果展示、历史记录
- 模型转换功能，支持模型转换，结果展示、历史记录
- 模型部署功能，支持转换结果下载、SDK编译
- 模型验证功能，支持性能验证与精度验证，支持结果查看、历史记录

## [26.4.1] - 2026-04-30

新增

- NPU侧 WSL 通路
- CPU侧 Windows 通路
- 量化、部署、评估界面逻辑优化，易用性提升
